# SNES Mouse test ROM

`mousetest.sfc` is a small test ROM for the SNES Mouse in controller port 1. It works with an original SNES Mouse on a GPIO controller port and with a USB mouse, and also runs on other emulators and on original hardware.

Copy `mousetest.sfc` to the SD card and start it like any game. The screen shows:

| Line | Content |
| --- | --- |
| PORT 1 | `SNES MOUSE` when port 1 reports the mouse signature, otherwise `NOT CONNECTED`. |
| CURSOR | The position of the arrow cursor, X from 0 to 255 and Y from 0 to 223. The tip of the arrow is the position shown. |
| MOTION | The movement reported in the last frame. Moving right and down gives positive values. |
| LEFT, RIGHT | `ON` while the button is held, with a counter of the presses. The cursor is green while the left button is held, red for the right button and yellow for both. |
| SENSITIVITY | The sensitivity setting the mouse reports (0 to 2). The emulator keeps an original mouse at 0. |
| RAW | The 32-bit mouse report in hexadecimal: bits 1-8, bits 9-16 (buttons, sensitivity and signature), the Y byte and the X byte. |

The ROM reads the mouse the way Nintendo's driver does: the automatic controller read supplies the first 16 bits, and the program clocks in the remaining 16 bits through `$4016`.

## Rebuilding

The ROM is generated by `mousetest.py`, which contains a minimal 65816 assembler and the test program. It requires only Python 3; no SNES assembler is needed. The font is read from `pico_shared/font_8x8.h`.

```sh
tools/mousetest/mousetest.py              # writes tools/mousetest/mousetest.sfc
tools/mousetest/mousetest.py out.sfc      # or to another file
```

## Testing without hardware

The host harness in [tools/host-harness](../host-harness) can run the ROM with its scripted mouse, which moves in a circle and holds the left button for 10 frames from `MOUSE_CLICK` on:

```sh
MOUSE=1 MOUSE_CLICK=60 tools/host-harness/fb1_nolut tools/mousetest/mousetest.sfc out mt 130 10
```
